# SauceDemo 电商Web测试项目
 软件测试练手项目，用于求职展示

## 📌 项目介绍
针对SauceDemo模拟电商网站开展手工功能测试，编写测试计划、设计功能测试用例，执行测试，发现、记录软件缺陷。

## 📁 项目文件说明
- `test_cases.xlsx`：全套功能测试用例（正向、边界、异常场景）
- `bug_report.md`：缺陷报告，记录复现的BUG
- `test_plan.md`：测试计划文档
- `screenshots`：存放所有缺陷截图

## 🧪 测试环境
操作系统：Windows11
浏览器：Microsoft Edge

## 🐛 已发现缺陷列表
1. problem_user：商品列表页面全部显示小狗图片，图片与商品信息不匹配
2. visual_user：商品页排序下拉框UI错位，文字被遮挡
3. problem_user：结算收货信息页，填写Last Name会覆盖First Name输入的内容（严重缺陷）
